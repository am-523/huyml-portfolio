# Huy Phan — Award-Winning Designer Portfolio

A faithful, high-fidelity recreation of the award-winning designer portfolio inspired by **Huy Phan (huyml.co)**, featuring custom typography (BT Grotesk, BT Glyphius, F37 Bolton), magnetic interactions, and editorial layouts.

## ✨ Highlights & Features

- **Editorial Typography**: Custom WOFF2 web typography with dynamic scaling and fluid letterspacing.
- **Interactive Cursor & Physics**: Custom magnetic hover effects, interactive cards, and smooth micro-transitions.
- **Awwwards-Standard Aesthetics**: Gapless bento grid showcases, project case study layouts, and monochrome elegance.
- **Lenis Smooth Scroll**: Fluid, inertial page navigation.

## 🛠️ Tech Stack

- **Vite** — Next generation frontend build tool
- **HTML5 & Vanilla CSS** — High-end agency typography and design system
- **JavaScript (ES Modules)** — Interactive micro-animations
- **Lenis** — Modern smooth scroll library

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/am-523/huyml-portfolio.git
cd huyml-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
